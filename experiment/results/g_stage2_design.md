# G0-G3 阶段二：递进分组与控制变量

预期：四组只在执行反馈信息上不同；优化指令、初始代码、模型、输出上限、题目和额外测试保持一致。

实际：冻结 17 道通过阶段一反馈稳定性检查的题目，其中主组 12 题、短任务对照 5 题。G0 反馈为空；G1 增加固定测试集整体耗时；G2 原样包含 G1 并增加最慢测试与耗时；G3 原样包含 G2 并增加最慢测试中的热点源码、执行次数和近似行耗时。离线检查确认所有组共享同一提示前缀、优化指令和初始代码，反馈块严格逐级包含。每组预设两次独立生成，按题目和轮次轮换调用顺序。

判定：控制变量与信息递进达标。提示长度随反馈增加是研究对象本身的成本，需要在最终报告中与 API Token 和延迟同时呈现。任务清单见 `g_manifest.json`，逐次完整提示将随结果保存。
