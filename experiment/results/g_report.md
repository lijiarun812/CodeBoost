- 完成题目：17；每题每组 2 次生成，四组共 136 次；正确性失败按未优化成功计入分母。

- 速度由相同测试集、相同重复次数、各三次计时的中位数成对计算。

## 反馈成本与限制

- G1 计时采集中位耗时 0.260s；G2 复用该次测量得到的最慢测试，增量采集成本接近零；G3 热点剖析额外中位耗时 0.105s。
- 提示 Token 与 API 延迟见上表；完整用量及原始计时在 JSON 结果中。
- 三次计时的极差/中位数：原测试中位 3.9%，额外测试中位 4.3%；超过 20% 的候选分别为 2/125 和 1/125。
- 热点耗时是跟踪器的近似值，不能与普通计时的绝对值直接比较。
- 额外测试来自同一基准的不同随机种子；题目数量及每组仅两次生成限制了统计推断。
