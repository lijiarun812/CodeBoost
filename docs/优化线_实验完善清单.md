> 依据：`experiment/results/g_report.md`（G0–G3 递进反馈实验）、`g_analysis.json`、`effibench_v2_*`。
> 原则：**先零成本重算，再本地测量，最后才花钱**；不按结果重选题目。

## 0. 当前结论（原文数据，直接引用）

主组 12 题、每组 2 次生成（24 组内重复），成功优化数 20 / 20 / 22 / 22：

| 组 | 成功优化 | 正确候选额外测试中位加速 | Token 中位 | 延迟中位 |
|---|---:|---:|---:|---:|
| G0（普通优化） | 20/24 | 13.90x | 646 | 4.30s |
| G1（+总耗时反馈） | 20/24 | 15.00x | 670 | 4.98s |
| G2（+最慢测试） | 22/24 | 23.94x | 924 | 5.34s |
| G3（+热点区域） | 22/24 | 16.03x | 1128 | 5.52s |

成对比较（唯一可信的口径）：G0→G1 **1.02**、G1→G2 **1.02**、G2→G3 **0.81**。

> **G2→G3 = 0.81 是轻微负效应，不是「无额外收益」。报告与答辩必须如实写，不得淡化。**

## 4. 明确不要做的四件

1. 不要按结果重选题目（`stage4_findings.md` 已承诺，守住即加分）；

3. 不要在升档数据上报时间（放大 100–2000 倍）；
4. 不要声称空间收益——除非第 4 项真跑出差异且样本 ≥10 题。

# 附录：能产出「真实正效应」的四条实验设计

> 前提：**不做结果导向的选题**。下面每条都先写死假设与判据（预注册），再跑；无论正负都如实入表。
> 排序依据是「在当前数据条件下产出正效应的概率」，不是「哪个看起来更高级」。

## 设计 A（最可能出正效应）：内存感知优化

**为什么可能有效**：现有四组（G0–G3）全部只反馈时间，模型没有任何压缩内存的动机；而基线代码普遍存在「中间列表、重复构造、递归深拷贝」等结构性问题，被告知内存目标后改动空间很大。这类优化通常**时间持平、内存显著下降**，正好命中老师第 3 条「同时优化空间」。

**最小可行实验（MVP）**

| 项 | 设定 |
|---|---|
| 题目 | 8 题，取 `peak_tm ≥ 0.05 MB` 的子集（用 `tools/scan_space_signal.py` 筛） |
| 组别 | M0 = 现有 G0 提示词；M1 = M0 + 「额外约束：降低峰值内存，避免创建中间列表/深拷贝」 |
| 生成 | 每题每组 2 次，共 32 次调用 |
| 测量 | 2×10⁵ 升档档位，只报 `peak_tracemalloc_mb` / `peak_rss_mb`；时间同档测量仅作回退约束 |
| 判据 | D 的 `acceptance.py`：内存降 ≥10% 且时间回退 ≤10%（或反之） |
| 成功线 | M1 在配对题上内存降幅中位 ≥10%，且时间回退中位 ≤10% |

**预期风险**：若 M1 与 M0 内存无差别，说明「模型本来就在省内存」，此时如实报零效应，并转设计 B。

## 设计 B（次可能）：二次优化（在已优化代码上再优化）

**为什么可能有效**：现有实验中四组差距被「弱初始代码」淹没（短任务对照四组都是 50 倍以上，说明首轮收益来自共同的烂起点）。把起点换成 **G2 的 final_code**，再做一轮优化，才考验反馈粒度是否有用。

| 项 | 设定 |
|---|---|
| 题目 | 12 题，取 G2 成功的题 |
| 组别 | S0 = 普通优化（无反馈）；S1 = 热点区域反馈；S2 = 总耗时反馈 |
| 生成 | 每组每题 2 次，共 72 次调用 |
| 判据 | 同题配对比较，报配对中位比 + bootstrap CI（`eval/stats.py`） |
| 成功线 | S1/S0 配对中位比 ≥1.05 且 CI 下界 >1 |

**预期风险**：二次优化空间本来就小，可能全部持平；那也是一个有意义的结论（「反馈收益集中在首轮」）。

## 设计 C（零成本，先把结论做实）

**目的**：找出「反馈粒度对哪类题有效」，而不是笼统说无效。

1. 用 `g_analysis.json` 按 `baseline_ms` 分层（<1 ms / 1–20 ms / >20 ms），各层分别算四组的成功数与配对中位比；
2. 全部结论改成**配对**口径（同题、同初始代码），配 bootstrap 95% CI；
3. 报「原测试加速比 vs 额外测试加速比」的一致性（相关系数 + 反转题数）。

**产出**：一张分层配对表。即使总体无效应，也可能在某一层出现正效应——这是可写进报告的合法结论。

## 设计 D（补口径，防止答辩被问倒）

把 G0–G3 的提示词按 `schema v1.1` 落成 `requested_method` / `degrade_reason`，并把四组的 token、延迟、剖析耗时并列成「成本表」。这不是新实验，但答辩必被问到「代价多少」。

## 执行顺序与预算

| 顺序 | 设计 | 调用量 | 预计产出 |
|---|---|---|---|
| 1 | C（零成本） | 0 | 分层配对表 |
| 2 | A（MVP） | 32 | **最可能的空间正效应** |
| 3 | B | 72 | 反馈粒度的真实检验 |
| 4 | D | 0 | 成本表 + 口径合规 |
