# 口径切换说明（旧尺子 → 新尺子）

> 一句话：**从今天起，`eval/harness.py` 是唯一测量实现**。中期数字保留但标 `legacy-psutil`，
> 不与新数字进同一张表；需要对照时用「同题重测」的方式另出一列。

---

## 一、新尺子与旧尺子的四处差别

| 维度 | 旧尺子（中期） | 新尺子（eval/harness.py） |
|---|---|---|
| 时间估计量 | 3 次取中位数（逐 assert 分别计时后求和） | **E=12 批，去最高/最低各 2 个取均值**；保留 `raw_ms` |
| 内存 | psutil RSS 的**时间积分**（MB·s），热身后退化为 0 → “假 100%” | **双口径**：`peak_tracemalloc_mb`（Python 分配峰值）+ `peak_rss_mb`（进程峰值），**不用积分** |
| 超时 | 硬超时（180s / 20s）到点直接杀，判成失败 | **心跳看门狗**（5s 心跳，30s 无心跳才杀）+ 单档预算 + **降档重试**；超时是独立 `status=timeout` |
| 状态 | 只有 ok / 失败（原因混在 error 字符串里） | **五类**：ok / incorrect / timeout / resource_exceeded / api_failed |

## 三、为什么这些数字和中期不一样（必须写进报告）

| 旧值 | 新值 | 差异来源 |
|---|---|---|
| HE/31 “0.122 ms” | 13.33 ms | 旧值是**模型生成的 sqrt 版代码**，新值是**数据集 canonical 的 O(n) 循环**；两者不是同一个被测对象 |
| HE/96 “72.7 ms” | 0.35 ms | 同上：旧值是模型代码在大输入下的耗时，新值是 canonical 在小输入下的耗时 |
| HE/40 “1.171x” | —（新尺子量的是绝对耗时 0.1125 ms） | 旧值是**加速比**（经过输入复用修正后），新尺子是**同一份代码的绝对耗时基线**；要算加速比得再用 base/优化版各测一次 |
| “内存下降 36%” | — | 旧口径是 RSS 时间积分；新尺子**不给积分**，只给双峰值，两者不可换算 |

> 规则：**旧值只能出现在“对照列”**，且必须注明 `legacy-psutil`。新表的主口径一律用 `mean_trimmed_ms`。

## 四、旧结果的处置（不作废中期成绩）

1. `results/repro/repro_*.json`（4 模型 × 100 题）**原地保留**，汇总表里标注 `legacy-psutil`；
2. 用新尺子抽 **20–30 题**重测（同题、同代码），出「旧口径 / 新口径」对照表；
3. 对照表只回答一个问题：**口径差异带来多少量级差**（例如旧 27.5% vs 新 X%），不重新解释方法效果。

## 五、回归要求

任何人改动 `eval/harness.py` 后，必须跑：

```powershell
python eval\harness.py --selftest
python eval\harness.py --dataset humaneval --tasks 31,40,55,59,60,63,96,120,123,130,139,147 --out-dir results/golden
```

体检判据（见 `eval/schema.md` 第五节）：`protocol_version` 正确、12 题全 ok、CV ≤ 10%、
新值相对本文件第二节浮动 ≤ 20%。任何一条不满足，说明尺子被改坏了，禁止合并。

## 六、已知数据集缺陷（交给 B 处理）

EffiBench 的 `small_test_cases` 与 `canonical_solution` **并不总是配套**。实测：

| 题 | 现象 | 处理建议 |
|---|---|---|
| `EffiBench/100`（Same Tree） | 测试块把**列表**直接传给 `isSameTree`（`solution.isSameTree([1,2,3], [1,2,3])`），而标准解要的是 `TreeNode` | 要么在测试块前加 `build_tree()` 转换，要么把该题从冻结题库剔除 |

> harness 对这类题的行为是正确的：`status=incorrect`，并保留原始 `error`。
> **题库适配与筛选属于 B 的职责**（`eval/datasets.py` / `difficulty.py`），A 只负责“测不准要说出来”。
