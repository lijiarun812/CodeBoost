# G0–G3、F0–F4 与 Ours 的统一对照草案

本文件对应 `optimize/unified_control.json`；运行
`python -m optimize.control_config` 只校验配置并列出阻塞项，不调用模型。
配置当前关闭运行和正式 Result 写入。B 的 91 题冻结快照现存于
`results/bank/`，但本草案还没有固定统一对照的题目／档位、独立 holdout
和调用预算。旧 80 题列表是 provisional，不能作为冻结清单。

## 已执行的 G0–G3 实际口径

证据入口：`experiment/run_feedback_g.py`、`collect_feedback_g.py`、
`analyze_feedback_g.py`、`llm_client.py`、`effibench_worker.py`。

- G0：无执行反馈；G1：固定测试总耗时（ns）；G2：G1 加最慢测试及其耗时（ns）；
  G3：G2 加最慢测试的前五热点源码行、执行次数和跟踪器近似 `profile_ns`。
- 四组内部共用 EffiBench 公开 GPT-3.5 正确代码、截断至 4500 字符的题面、
  同一优化指令和 system prompt。筛题后的 17 题中，每组每题生成 2 次；
  题目和反馈在生成前冻结。历史模型是 `qwen4-max`，`max_tokens=2048`，
  客户端对该模型强制 `temperature=0.7`、关闭 thinking；API 请求没有传 seed。
  API 超时 90 秒，免费额度耗尽即停，未预设统一的调用、token、金额上限。
- 候选先用原测试（25 秒）及额外测试（15 秒）检查正确性。后续计时由旧
  `effibench_worker.py` 对每个 assert 用 `perf_counter_ns`，三次测量取中位数；
  原测试与额外测试分别自适应重复。它不是 `eval.harness.measure_task()` 的
  E=12 去极值均值，也不测本期双峰值空间指标。

## 与本期 F 档的关系

- F0 与 G0 都不给测量反馈，但题面、起始代码来源、共同提示框架和输出格式不同。
- F1 只给共享 harness 的全任务 `mean_trimmed_ms`；G1 给旧 worker 的总 ns。
- F2 给共享 harness 的最慢用例及毫秒；G2 **同时保留 G1 的总 ns**，因此 F2 与 G2 不是同一提示档。
- F3 给最慢用例及逐行执行次数，不把次数当行耗时；G3 在 G2 上额外给
  跟踪器近似 `profile_ns`。两者的工具、数字和提示长度都不同。
- F4 给周围原样源码、函数／循环作用域、已剖析行时间之和的百分比及
  程序级空间证据；小用例或诊断失败按真实生效档降级。D 的 Ours 使用该
  F4 反馈加联合接受主循环；只有冻结题库、完整反馈和 G1–G6 闸门都通过，
  才能写 schema 的 `method=ours`。Ours 是 F4 的正式方法名及联合流程，
  不是把 G3 改名后得到的第十个反馈档。

上述历史 G 结果与本期 F/Ours 的题集、模型版本、初始代码、提示词、采样参数、
生成次数、正确性门禁和计时口径均未统一，不能跨协议合并或直接排名。

## 统一重跑的固定项

`optimize/unified_control.json` 给所有组共用一份 Task 清单、每题唯一
`tier + args_hash + test`、`Task.code`、`Task.description`、
`optimize.prompts.render_prompt` 框架和版本。模型的实际返回版本、
temperature、seed、max_tokens、thinking、每题每档生成次数以及整批调用、
token、金额上限在开始前固定；同题同轮的各组独立生成候选。

所有候选先通过同一冻结测试及独立 holdout 正确性检查，再用
`eval.harness.measure_task()` 同档测量；时间只用 `mean_trimmed_ms`，空间只用
`peak_tracemalloc_mb`，RSS 只作资源门禁。`task_id + tier + args_hash` 必须配对。
行级剖析只定位反馈，不进入 speedup、内存收益或 Result.time。
G0–G3 若重跑，需编写从共享诊断构造其**原有语义**的适配器，并保留 G 标签；
尤其 G3 的旧 `profile_ns` 不能冒充 `line_profiler` 百分比。若选择改变 G3
反馈定义，则应给新名称和提示词版本，不能与历史 G3 合并。
